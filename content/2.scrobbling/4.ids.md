Объект `ids` — то, по чему MyShows находит тайтл в каталоге. Передавайте всё, что знаете:
чем больше идентификаторов, тем надёжнее сопоставление. Минимум — один.

Если ID нет вообще, отправляйте `title` + `year` (для эпизодов ещё `season` и `number`) —
сопоставление по названию менее точное, но работает.

## Список ключей

| Ключ | Тип | Где применим | Примечание |
|---|---|---|---|
| `myshow` | `number` | movie, show, episode | Внутренний ID MyShows — самый точный вариант |
| `imdb` | `string` | movie, show, episode | Формат `tt15239678` |
| `tmdb` | `string` | movie, show, episode | Строка — см. [расхождение с Trakt](/rules/trakt-simkl#известное-расхождение-типов) |
| `tvdb` | `string` | movie, show, episode | |
| `slug` | `string` | movie, show, episode | URL-слаг |
| `trakt` | `number` | movie, show, episode | Внутренний ID Trakt |
| `simkl` | `number` | movie, show, episode | Внутренний ID Simkl |
| `anidb` | `number` | movie, show, episode | Аниме |
| `anilist` | `number` | movie, show, episode | Аниме |
| `kitsu` | `number` | movie, show, episode | Аниме |
| `shikimori` | `number` | movie, show, episode | Аниме |
| `mal` | `number` | movie, show, episode | MyAnimeList |
| `kinopoisk` | `number` | movie, show, episode | Кинопоиск |
| `netflix` | `string` | movie, show | |
| `hulu` | `number` | movie, show | |
| `crunchyroll` | `number` | movie, show | |
| `zap2It` | `string` | show | TV Listings |
| `moviedb` | `string` | movie | Устаревший алиас `tmdb` |
| `tvrage` | `string` | movie, show, episode | Legacy, сервис закрыт |
