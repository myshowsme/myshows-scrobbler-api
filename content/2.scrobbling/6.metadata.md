Объект `metadata` описывает, в каком качестве шёл просмотр. Целиком необязателен —
MyShows использует его для статистики пользователя.

| Поле | Тип | Описание |
|---|---|---|
| `media_type` | `enum` | Носитель |
| `resolution` | `enum` | Разрешение |
| `hdr` | `enum` | HDR-формат |
| `audio` | `enum` | Аудиокодек |
| `audio_channels` | `enum` | Конфигурация каналов |
| `audio_language` | `string` | Язык дорожки, ISO 639-1: `"ru"`, `"en"`, `"ja"` |
| `3d` | `boolean` | Просмотр в 3D |

## Значения enum

  :::accordion-item{label="media_type — 8 значений" icon="i-lucide-disc"}

  :::

  :::accordion-item{label="resolution — 8 значений" icon="i-lucide-monitor"}

::note

Значения генерируются из
