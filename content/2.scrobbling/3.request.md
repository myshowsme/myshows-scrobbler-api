Два варианта: фильм или эпизод сериала.

::code-group

```json [Фильм]
{
  "progress": 45.2,
  "source_app": "my-player",
  "app_version": "1.4.0",
  "movie": {
    "title": "Dune: Part Two",
    "original_title": "Dune: Part Two",
    "year": 2024,
    "runtime": 166,
    "content_rating": "PG-13",
    "ids": { "imdb": "tt15239678", "tmdb": "693134" },
    "metadata": {
      "resolution": "uhd_4k",
      "hdr": "dolby_vision",
      "audio": "dolby_atmos",
      "audio_channels": "7.1",
      "audio_language": "en"
    }
  }
}
```

```json [Эпизод]
{
  "progress": 45.2,
  "source_app": "my-player",
  "dub_team": "AniLibria",
  "show": {
    "title": "Frieren: Beyond Journey's End",
    "original_title": "葬送のフリーレン",
    "year": 2023,
    "ids": { "imdb": "tt22248376", "shikimori": 52991 }
  },
  "episode": {
    "season": 1,
    "number": 12,
    "title": "A Real Hero",
    "runtime": 24,
    "metadata": { "resolution": "hd_1080p", "audio_language": "ja" }
  }
}
```

::

Фильм описывается объектом `movie`, эпизод — парой `show` + `episode`.

## Общие поля

| Поле | Тип | Обяз. | Описание |
|---|---|---|---|
| `progress` | `number` | **да** | Прогресс в процентах, 0.0–100.0 |
| `app_version` | `string` | — | Версия вашего приложения |
| `app_date` | `string` | — | Дата сборки, `YYYY-MM-DD` |
| `source_app` | `string` | — | Идентификатор источника: `"plex"`, `"kodi"`, `"lampa"`, `"browser"` |
| `dub_team` | `string` | — | Студия озвучки: `"AniLibria"`, `"Кубик в Кубе"` |
| `rating` | `number` | — | Оценка пользователя 1–10. Обычно отправляется вместе с `/stop` |

`source_app`, `dub_team` и `rating` — расширения MyShows. Trakt и Simkl их игнорируют,
так что наличие этих полей не мешает отправить тот же payload туда.

## Объекты `movie`, `show`, `episode`

| Поле | Тип | `movie` | `show` | `episode` | Описание |
|---|---|:---:|:---:|:---:|---|
| `title` | `string` | ✓ | ✓ | ✓ | Название |
| `original_title` | `string` | ✓ | ✓ | — | Оригинальное название |
| `year` | `number` | ✓ | ✓ | — | Год выхода / год начала |
| `season` | `number` | — | — | ✓ | Номер сезона |
| `number` | `number` | — | — | ✓ | Номер эпизода в сезоне |
| `runtime` | `number` | ✓ | — | ✓ | Длительность в минутах |
| `content_rating` | `string` | ✓ | ✓ | — | Возрастной рейтинг: `"PG-13"`, `"R"`, `"18+"` |
| `ids` | `object` | **да** | **да** | ✓ | [Идентификаторы](/scrobbling/ids) |
| `metadata` | `object` | ✓ | — | ✓ | [Метаданные качества](/scrobbling/metadata) |

::note{to="/scrobbling/ids"}
Объект `ids` обязателен для `movie` и `show` — по нему MyShows находит тайтл в каталоге.
::
