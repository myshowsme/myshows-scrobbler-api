Scrobbling marks what users watch in real time. The player tells MyShows when the user
starts watching, where they are now, and when they finish. The user doesn't have to
mark anything by hand.

The API is built for third-party developers: players, plugins, media servers, mobile
clients. The request format is a superset of the Trakt and Simkl scrobble APIs, so a
single payload can be sent to all three services unchanged.

## Reference implementation

The [MyShows Scrobbler](https://github.com/myshowsme/myshows-scrobbler) code works well
as a reference. These are the key files:

::field-group
  ::field{name="src/scrobblers/converter.ts" type="payload builder"}
  Turns player state into a request body. [View on GitHub](https://github.com/myshowsme/myshows-scrobbler/blob/main/src/scrobblers/converter.ts).
  ::

  ::field{name="src/scrobblers/myshows.ts" type="HTTP layer"}
