Every request needs an `Authorization` header with the user's personal token:

```http
Authorization: Bearer <token>
```

The user gets the token on their own from the
[profile](https://en.myshows.me/profile/watch-history/) page and pastes it into your app.
The token is tied to the account and doesn't expire.

## Token handling requirements

- **ASCII only.** Check this before sending. That way you catch the case where the user
  copied text with Cyrillic characters and can show a clear error instead of an obscure
  transport failure.
- **Don't log the token**, and don't show it in the UI once it's saved. The reference
  client masks it when reading the configuration.
- **In client-server apps**, keep the token on your side and don't send it to the
  browser.

::tip{to="/en/scrobbling/endpoints#get-check"}
Call `GET /check` as soon as the user enters a token, so you can show whether it was
accepted without waiting for the first scrobble.
::
