Get a token from your [profile](https://en.myshows.me/profile/watch-history/), check it and
send your first scrobble.

::steps{level="3"}

### Check the token

```bash [Terminal]
curl https://myshows.me/scrobble/check \
  -H "Authorization: Bearer $MYSHOWS_TOKEN"
```

If the token is accepted, you can start sending scrobbles. See
[Authentication](/en/start/authentication) for details.

### The user starts watching an episode

```bash [Terminal]
curl https://myshows.me/scrobble/start \
  -H "Authorization: Bearer $MYSHOWS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "progress": 2.5,
    "source_app": "my-player",
    "show":    { "title": "Severance", "year": 2022, "ids": { "imdb": "tt11280740" } },
    "episode": { "season": 2, "number": 1 }
  }'
```

### The user finishes watching, so mark it as watched

```bash [Terminal]
curl https://myshows.me/scrobble/stop \
  -H "Authorization: Bearer $MYSHOWS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "progress": 92.0,
    "source_app": "my-player",
    "show":    { "title": "Severance", "year": 2022, "ids": { "imdb": "tt11280740" } },
    "episode": { "season": 2, "number": 1 }
  }'
```

::

That's it. The episode is marked as watched in the user's profile.

::tip{to="/en/scrobbling/lifecycle"}
In a real player, regular `/pause` calls go between `/start` and `/stop` to update the
position. The "How scrobbling works" page describes how to build that loop.
::
