Base URL: `https://myshows.me/scrobble`

Every request needs the [`Authorization`](/en/start/authentication) header.

## `GET /check`

Checks the token. Call it when the user enters a token, so you can show right away
whether it was accepted.

```bash [Terminal]
curl https://myshows.me/scrobble/check \
  -H "Authorization: Bearer $TOKEN"
```

::note
Only look at the HTTP status. You don't need to parse the response body. The reference
client works the same way.
::

## `POST /start`

Opens a viewing session. The body is a [request object](/en/scrobbling/request).

## `POST /pause`

Updates the position in an open session. The body is the same, only `progress` changes.

## `POST /stop`

Closes the session. If `progress` is above the [threshold](/en/scrobbling/lifecycle#watched-threshold),
the view is marked in the profile.

::note
All three `POST` endpoints accept the same [request body](/en/scrobbling/request) and
return the same [response object](/en/scrobbling/response).
::
