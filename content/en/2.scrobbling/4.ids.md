The `ids` object is what MyShows uses to find a title in the catalog. Send everything you
know: the more identifiers, the more reliable the match. At least one is required.

If you have no IDs at all, send `title` + `year` (plus `season` and `number` for
episodes). Matching by title is less precise, but it works.

## Key list

| Key | Type | Applies to | Note |
|---|---|---|---|
| `myshow` | `number` | movie, show, episode | Internal MyShows ID, the most precise option |
| `imdb` | `string` | movie, show, episode | Format `tt15239678` |
| `tmdb` | `string` | movie, show, episode | A string, see the [mismatch with Trakt](/en/rules/trakt-simkl#known-type-mismatch) |
| `tvdb` | `string` | movie, show, episode | |
| `slug` | `string` | movie, show, episode | URL slug |
| `trakt` | `number` | movie, show, episode | Internal Trakt ID |
| `simkl` | `number` | movie, show, episode | Internal Simkl ID |
| `anidb` | `number` | movie, show, episode | Anime |
| `anilist` | `number` | movie, show, episode | Anime |
| `kitsu` | `number` | movie, show, episode | Anime |
| `shikimori` | `number` | movie, show, episode | Anime |
| `mal` | `number` | movie, show, episode | MyAnimeList |
| `kinopoisk` | `number` | movie, show, episode | Kinopoisk |
| `netflix` | `string` | movie, show | |
| `hulu` | `number` | movie, show | |
| `crunchyroll` | `number` | movie, show | |
| `zap2It` | `string` | show | TV Listings |
| `moviedb` | `string` | movie | Deprecated alias for `tmdb` |
| `tvrage` | `string` | movie, show, episode | Legacy, the service is shut down |
