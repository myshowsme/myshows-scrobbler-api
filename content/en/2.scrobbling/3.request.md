There are two variants: a movie or a TV episode.

::code-group

```json [Movie]
{
  "progress": 45.2,
  "source_app": "my-player",
  "app_version": "1.4.0",
  "movie": {
    "title": "Dune: Part Two",
    "original_title": "Dune: Part Two",
    "year": 2024,
    "runtime": 166,
    "content_rating": "PG-13",
    "ids": { "imdb": "tt15239678", "tmdb": "693134" },
    "metadata": {
      "resolution": "uhd_4k",
      "hdr": "dolby_vision",
      "audio": "dolby_atmos",
      "audio_channels": "7.1",
      "audio_language": "en"
    }
  }
}
```

```json [Episode]
{
  "progress": 45.2,
  "source_app": "my-player",
  "dub_team": "AniLibria",
  "show": {
    "title": "Frieren: Beyond Journey's End",
    "original_title": "葬送のフリーレン",
    "year": 2023,
    "ids": { "imdb": "tt22248376", "shikimori": 52991 }
  },
  "episode": {
    "season": 1,
    "number": 12,
    "title": "A Real Hero",
    "runtime": 24,
    "metadata": { "resolution": "hd_1080p", "audio_language": "ja" }
  }
}
```

::

A movie is described by a `movie` object, an episode by a `show` + `episode` pair.

## Common fields

| Field | Type | Req. | Description |
|---|---|---|---|
| `progress` | `number` | **yes** | Progress in percent, 0.0–100.0 |
| `app_version` | `string` | — | Your app version |
| `app_date` | `string` | — | Build date, `YYYY-MM-DD` |
| `source_app` | `string` | — | Source identifier: `"plex"`, `"kodi"`, `"lampa"`, `"browser"` |
| `dub_team` | `string` | — | Dubbing studio: `"AniLibria"`, `"Кубик в Кубе"` |
| `rating` | `number` | — | User rating 1–10. Usually sent with `/stop` |

`source_app`, `dub_team` and `rating` are MyShows extensions. Trakt and Simkl ignore
them, so these fields don't stop you from sending the same payload there.

## `movie`, `show` and `episode` objects

| Field | Type | `movie` | `show` | `episode` | Description |
|---|---|:---:|:---:|:---:|---|
| `title` | `string` | ✓ | ✓ | ✓ | Title |
| `original_title` | `string` | ✓ | ✓ | — | Original title |
| `year` | `number` | ✓ | ✓ | — | Release year / start year |
| `season` | `number` | — | — | ✓ | Season number |
| `number` | `number` | — | — | ✓ | Episode number within the season |
| `runtime` | `number` | ✓ | — | ✓ | Runtime in minutes |
| `content_rating` | `string` | ✓ | ✓ | — | Age rating: `"PG-13"`, `"R"`, `"18+"` |
| `ids` | `object` | **yes** | **yes** | ✓ | [Identifiers](/en/scrobbling/ids) |
| `metadata` | `object` | ✓ | — | ✓ | [Quality metadata](/en/scrobbling/metadata) |

::note{to="/en/scrobbling/ids"}
The `ids` object is required for `movie` and `show`. MyShows uses it to find the title
in the catalog.
::
