All three `POST` endpoints return the same object.

```json
{
  "id": 184756,
  "action": "scrobble",
  "progress": 92.0,
  "watched_at": "2026-08-16T19:24:11Z",
  "show":    { "title": "Severance", "year": 2022, "ids": { "imdb": "tt11280740" } },
  "episode": { "season": 2, "number": 1 }
}
```

| Field | Type | Description |
|---|---|---|
| `id` | `number` | Playback record ID |
| `action` | `enum` | `start` · `pause` · `scrobble` · `checkin` |
| `progress` | `number` | The progress the server recorded |
| `watched_at` | `string` | ISO 8601, when the view was marked. Present when `action: "scrobble"` |
| `expires_at` | `string` | ISO 8601, when the session expires |
| `movie` / `show` + `episode` | `object` | The title as MyShows recognized it |

::tip
---
icon: i-lucide-scan-search
---
**Checking recognition.** The returned title object is useful for verification: if
MyShows recognized something other than what you sent, you'll see it right away.
::
