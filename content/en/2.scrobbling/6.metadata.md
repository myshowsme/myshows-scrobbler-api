The `metadata` object describes the quality the content was watched in. It's entirely
optional. MyShows uses it for the user's statistics.

| Field | Type | Description |
|---|---|---|
| `media_type` | `enum` | Media type |
| `resolution` | `enum` | Resolution |
| `hdr` | `enum` | HDR format |
| `audio` | `enum` | Audio codec |
| `audio_channels` | `enum` | Channel layout |
| `audio_language` | `string` | Audio track language, ISO 639-1: `"ru"`, `"en"`, `"ja"` |
| `3d` | `boolean` | Watched in 3D |
