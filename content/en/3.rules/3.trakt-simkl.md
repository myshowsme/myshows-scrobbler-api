The format is deliberately a superset of the Trakt and Simkl scrobble APIs: both ignore
unknown fields, so the same payload goes to all three services unchanged. If you already
integrate with Trakt or Simkl, supporting MyShows means a new base URL and token, not a
new mapping.

## Field support table

| Field | MyShows | Trakt | Simkl |
|---|:---:|:---:|:---:|
| `progress`, `movie`, `show`, `episode` | ✅ | ✅ | ✅ |
| `app_version`, `app_date` | ✅ | ✅ | ✅ |
| `ids.imdb`, `ids.tmdb`, `ids.tvdb`, `ids.slug` | ✅ | ✅ | ✅ |
| `ids.anidb`, `ids.mal`, `ids.netflix`, `ids.hulu` | ✅ | — | ✅ |
| `ids.shikimori`, `ids.kinopoisk`, `ids.anilist`, `ids.kitsu` | ✅ | — | — |
| `metadata.*` | ✅ | ✅ (in `/sync/collection`) | — |
| `source_app`, `dub_team`, `rating` | ✅ | — | — |
| `original_title`, `content_rating`, `runtime` | ✅ | — | — |

## Known type mismatch

::note
---
icon: i-lucide-type
---
Trakt declares `ids.tmdb` as a `number`, Simkl as a `string`. In practice both accept a
string, so in this API the type is **`string`**.
::

## Bulk history import

There is no bulk history import.
