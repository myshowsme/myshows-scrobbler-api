Возьмите токен в [профиле](https://myshows.me/profile/watch-history/), проверьте его и
отправьте первый скробл.

::steps{level="3"}

### Проверяем токен

```bash [Terminal]
curl https://myshows.me/scrobble/check \
  -H "Authorization: Bearer $MYSHOWS_TOKEN"
```

Если токен принят, дальше можно слать скроблы. Подробнее — в
[Аутентификации](/start/authentication).

### Пользователь начал смотреть эпизод

```bash [Terminal]
curl https://myshows.me/scrobble/start \
  -H "Authorization: Bearer $MYSHOWS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "progress": 2.5,
    "source_app": "my-player",
    "show":    { "title": "Severance", "year": 2022, "ids": { "imdb": "tt11280740" } },
    "episode": { "season": 2, "number": 1 }
  }'
```

### Пользователь досмотрел — отмечаем просмотр

```bash [Terminal]
curl https://myshows.me/scrobble/stop \
  -H "Authorization: Bearer $MYSHOWS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "progress": 92.0,
    "source_app": "my-player",
    "show":    { "title": "Severance", "year": 2022, "ids": { "imdb": "tt11280740" } },
    "episode": { "season": 2, "number": 1 }
  }'
```

::

Всё. Эпизод отмечен просмотренным в профиле пользователя.

::tip{to="/scrobbling/lifecycle"}
В реальном плеере между `/start` и `/stop` идут регулярные `/pause` — они обновляют
позицию. Как выстроить цикл, описано в разделе «Как работает скробблинг».
::
